# SpecImpact M8 v3 development artifacts

These are the frozen development-only M8 baselines trained on TRAIN and
selected using VALIDATION from `impact-dataset-v3`. TEST labels were not used
for fitting or selection. The primary pre-registered baseline is Logistic
Regression Feature Set A; the heuristic, Feature Set B, Random Forest, and
XGBoost baselines are retained for comparison.
