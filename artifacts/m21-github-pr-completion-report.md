New command: specimpact pr
  --workspace DIR        .specimpact/ workspace directory (default: .)
  --dry-run              Print what would happen; exit 0, no changes made
  --base-branch BRANCH   Base branch for PR (default: repo default branch)

Full workflow (non-dry-run):
  1. Load migration-plan.json + analysis.json + validation-result.json
  2. find_git_root(repo_path) — walks up from repo dir to find .git
  3. get_remote_url → parse_github_owner_repo (HTTPS and SSH both supported)
  4. GitHubClient.from_env() — reads GITHUB_TOKEN; clear error if missing
  5. gh.get_default_branch() — unless --base-branch overrides
  6. Create branch: specimpact/migration-<timestamp>-<patch-id-prefix>
  7. apply_edits_to_working_tree — precondition check; raises on mismatch
  8. stage_and_commit — git add <files> && git commit -m <structured msg>
  9. push_branch — git push origin <branch>
  10. gh.create_draft_pr — always draft=True, never auto-merge
  11. Write .specimpact/pr-audit.json (number, URL, branch, commit, files, never_auto_merged=True)

Error recovery:
  - On GitError/GitHubClientError: restore_files (git checkout HEAD -- <files>)
    and delete_local_branch — source tree returned to pre-PR state.
