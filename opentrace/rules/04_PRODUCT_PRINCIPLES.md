# Product Principles

1. Deterministic analysis precedes generative behavior.
2. Correct uncertainty is better than fake certainty.
3. Outputs are evidence-backed and traceable to real inputs.
4. Explainability precedes impressive-looking scores.
5. Simple baselines precede ML sophistication.
6. Validation outweighs model confidence.
7. Humans approve before repository merge.
8. Reproducibility precedes claims.
9. Add complexity only when measured evidence justifies it.
10. Product displays derive from actual analysis, never fabricated demo data.
