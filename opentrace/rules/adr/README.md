# Architecture Decision Records

ADRs record consequential architecture decisions. Required format: Title, Status, Context, Decision, Alternatives Considered, Consequences, Revisit Conditions. Status is one of `PROPOSED`, `ACCEPTED`, `SUPERSEDED`, or `DEPRECATED`; frozen decisions are `ACCEPTED`. Accepted ADRs govern implementation with the main rules tree; changes require a superseding ADR, never silent drift or retroactive history edits.
