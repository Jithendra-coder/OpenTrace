# Future Work

Potential later work, only after evidence and ADR approval: expanded language/client support, richer OpenAPI compatibility rules, stronger interprocedural resolution, additional providers/models, policy/token routing, more robust sandbox deployment, additional repository hosts, organizational workflows, and carefully scoped multi-repository analysis.

These are not commitments and cannot be implemented opportunistically. Each proposal must identify the user problem, milestone, data/security impact, baseline, evaluation plan, operating cost and deprecation/rollback approach.
