# Demo Plan

Create demo assets only in their allowed later milestones. The eventual demonstration uses a real OpenAPI v1→v2 change and a real, controlled Python repository to show detected breaking changes, direct impact, indirect blast radius, ranking/risk, route, candidate patch, validation failure/success and optionally an authorized human-reviewable PR.

Every visible number, graph and patch must be generated during the demonstrated run and retain artifact provenance. Label unsupported/partial findings and failures. Never hardcode outputs, scripts that print expected success, fabricated statistics, or a PR that was not actually created.
