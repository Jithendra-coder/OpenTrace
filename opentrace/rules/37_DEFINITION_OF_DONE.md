# Definition of Done

## Generic milestone completion

A milestone is complete only when implementation exists; tests exist and pass; the real application path executes; real output is inspected; adversarial cases are checked; documentation is updated; limitations are recorded; no prohibited future functionality or hardcoded demonstration behavior was added.
