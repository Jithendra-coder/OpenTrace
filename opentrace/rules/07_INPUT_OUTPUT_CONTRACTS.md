# Input/Output Contracts

Every stage returns a typed success result or typed error result—never an empty success that hides a failure. All inputs and outputs carry artifact provenance/version; every uncertainty output carries a resolution or support state, assumptions, and warnings. “Done” means the stated output exists, valid/error/partial tests pass, artifacts are inspectable, and a real path ran at the stage’s allowed milestone.

| Stage | Input | Preconditions and process | Output | Error / uncertainty output | Expected tests and definition of done |
|---|---|---|---|---|---|
| Contract ingestion | Spec URI/content, declared format | Readable authorized YAML/JSON; parse without execution | Source artifact/hash, format, parse tree | unreadable/invalid syntax; `PARTIALLY_SUPPORTED` parser warnings | valid/invalid YAML+JSON; source/hash and error location verified |
| Contract normalization | Parsed contract | OpenAPI 3.x; resolve local structure while retaining source locations | `APISpecification`, operations/schemas/ref status | unsupported version/ref/cycle; unresolved refs preserved | nested/ref/composition fixtures and provenance verified |
| Breaking-change analysis | Normalized old/new specs | Comparable operation/schema identities; directional rules | `APIChange[]` | incomparable values; conditional compatibility assumptions/certainty | each category plus compatible optional addition; fields and reasons verified |
| Repository discovery | Authorized repo path/config | Canonical path, allowlisted scope; enumerate candidate Python files | `Repository`, `RepositoryFile[]` | access/ignored-file warnings; no silent omissions | nested/ignored/unreadable files and manifest verified |
| AST parsing | Repository files | Python source selected; parse without execution | module AST metadata, `CodeSymbol[]` | syntax/encoding failure; file marked `UNRESOLVED` | valid/malformed/decorated/nested/async symbols verified |
| Import resolution | AST/import environment evidence | Resolve only static local/import aliases | import bindings and resolution evidence | missing/re-export/dynamic import is `PARTIAL`/`UNRESOLVED` | direct/aliased/from-import/shadowed/local-post cases verified |
| HTTP call extraction | AST + import evidence | Recognized `requests`/`httpx` binding only | `APICallSite[]` | unknown client/call pattern warning | requests/httpx/client/async examples and no-execution guarantee verified |
| URL resolution | Call site + literal/data-flow evidence | Evaluate bounded static expressions only | host/path/method evidence | dynamic/partial URL remains `PARTIAL`/`UNRESOLVED` | literals, aliases, dynamic URLs, same path/different hosts verified |
| Payload-field extraction | Call AST/data-flow evidence | Request argument shape statically inspectable | request field `ImpactEvidence[]` | aliases/nested dynamic values retained as partial | dict, nested dict, alias, query-vs-body negatives verified |
| Response-field extraction | Call/use AST evidence | Response variable/use chain statically inspectable | response field `ImpactEvidence[]` | indirect/dynamic extraction warning | `.json`, nested extraction and request-vs-response negatives verified |
| Direct impact matching | `APIChange[]`, call sites/evidence | Canonical identities available or partial comparison permitted | `ImpactCandidate[]` with `impact_score` and evidence | unmatched/ambiguous/partial match; no probability pre-M9 | positives, unrelated-file negatives, feature contribution and real M4 slice verified |
| Call graph construction | Symbols, static calls, API calls | Local relation is statically evidenced | `DependencyEdge[]` | unresolved target/cycle warning, never invented edge | functions/methods/classes/nested/recursive edges verified |
| Blast-radius propagation | Direct candidates + edges + traversal policy | Bounded deterministic traversal | indirect exposures, paths/distances/scores | truncation/cycle/incomplete graph uncertainty | graph-derived transitive paths and no-certainty assertions verified |
| Risk assessment | Changes, impacts, graph features | M6 heuristic thresholds/config documented | `RiskAssessment[]` score/level/factors | missing coverage/features and assumptions | threshold/factor/uncertainty tests; no trained-model claim |
| Dataset generation | Versioned source scenarios/mutation config | M7 provenance/license/seed captured | synthetic and curated records | generator/source limitations | deterministic seed, metadata and label checks |
| Labeling | Scenario/evidence/label policy | Label definitions and annotator/generator traceable | versioned labels/disagreement state | ambiguous/unlabelable cases | agreement/uncertainty and no forced-label tests |
| Feature generation | Frozen dataset split and artifacts | Fit transforms on training only | feature artifact/schema | missing/out-of-distribution feature flags | train-only fitting and schema reproducibility tests |
| Impact ML | Versioned train split/features | M8; heuristic then Logistic Regression → Random Forest → XGBoost | model + `ImpactPrediction[]` | insufficient data/model failure; uncalibrated status | baseline comparison, split isolation and reproducibility verified |
| Calibration | Held-out validation data/model | M9 after model selection | calibration artifact and eligible `estimated_impact_probability` | inadequate calibration/coverage, probability withheld | Brier/ECE/held-out checks and reliability evidence verified |
| Deterministic migration | Supported `MigrationTask` with exact evidence | M10 rule applies safely | outcome and `GeneratedPatch` candidate | `NO_CHANGE`, `AI_REQUIRED`, `UNSUPPORTED`, rule failure | positive/negative/idempotence/golden patch tests |
| RouteForge dataset | Validated attempts/cost/latency/features | M11, provenance and policy labels available | offline routing records | censored/missing-cost/selection-bias flags | split/provenance/strategy-label tests |
| RouteForge prediction | Task/features/strategy catalog | M12+ available model/baseline | `RoutingCandidate[]` estimates | unavailable strategy/estimate uncertainty | baseline estimates and constraints verified |
| Routing optimization | Candidates + Economy/Balanced/Critical policy | M12+ thresholds/SLA declared | `RoutingDecision` rationale | no feasible route/policy violation | `NO_AI` vs `DETERMINISTIC`, cost/latency/success constraint tests |
| Context selection | Task + ranked relevance evidence | M14 bounded file/token/disclosure policy | `MigrationContext` | omitted evidence/reason and size uncertainty | selected-vs-raw experimental measurement and budget tests |
| AI generation | Context + provider configuration | M15, AI enabled, credentials authorized | provider-neutral patch/explanation/usage result | provider/timeout/refusal; AI-disabled controlled outcome | adapter contract mocks and deterministic AI-disabled real path |
| Patch application | Candidate patch + isolated repo copy | M16 patch targets confined to copy | apply status/changed-file list | conflict/path escape/apply failure | safe apply and rejection tests |
| Syntax validation | Applied isolated copy | Language syntax checker available | syntax status/diagnostics | checker failure/invalid syntax | valid/invalid patch tests |
| Test validation | Isolated configured copy | resource/network/privilege policy active | collection/pass/fail/timeout/exit result | setup/test/timeout errors, sanitized summary | documented isolated environment and cleanup verified |
| Adaptive escalation | Prior attempt + failure evidence + retry policy | M17 budget remains | new task/decision/attempt | exhausted/unsupported/no-new-evidence stop | evidence-aware non-duplicate bounded-retry tests |
| Feedback collection | Validated attempt and feature/route provenance | M18 immutable record policy | learning record | missing/censored labels | provenance and no-online-self-training tests |
| Async job execution | Authorized request/artifacts/config | M19 idempotency/quota policy | `AnalysisJob` state/events/artifacts | explicit failed/cancelled states | transitions/retry/idempotency/secret-redaction tests |
| Incremental analysis | Prior manifest + changed specs/files/config | M20 hash plus analyzer/schema/config versions valid | reused/invalidated artifacts and reasons | conservative invalidation warning | clean-equivalence and version/config invalidation tests |
| GitHub PR creation | Explicit authorization, validated reviewed patch | M21 scope/branch/repo identity checked | draft/reviewable PR + audit event | auth/conflict/rate/API error | mock/sandbox PR, no-auto-merge, human-review tests |
| Frontend consumption | Versioned backend artifact API | M22 artifact/provenance and empty/error states available | explanatory views | unavailable/partial/error display | contract/UI tests prove no fake KPIs or static successes |
| Multi-repository analysis | Authorized repositories + change/config | M23 per-repo provenance/access isolation | aggregate + per-repo impacts | inaccessible/incomplete repositories retained | authorization, aggregation and uncertainty tests |

No stage may be implemented before its milestone. A later stage may consume only the explicit artifacts above, not undeclared implementation details or raw arbitrary dictionaries.
