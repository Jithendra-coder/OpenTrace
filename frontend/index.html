OpenTrace CLI Setup Guide
Run migrations directly in terminal or CI/CD pipelines
Why the CLI? The CLI runs at native terminal speed. Your proprietary source code never leaves your computer, and checks can be automated inside GitHub Actions or pre-commit hooks to block breaking changes before merge.
Step 1: Download or Clone from GitHub
1
Clone the repository or download and extract the repository files:
git clone https://github.com/opentrace-ai/opentrace.git
Open your terminal and enter the project folder: cd opentrace
Step 2: Install in Development Mode
2
Run this command inside the project directory to register opentrace on your system PATH:
pip install -e .
Step 3: Verify Installation
3
Check that the CLI responds and optionally run the test suite:
opentrace --version
pytest tests/ -q
